# Expense Tracker

[Open the app](https://fsrkh12-arch.github.io/Expense-Tracker/)

I built Expense Tracker as a follow-up to my CS50 project and expanded it into a simple personal tool. It helped me understand my income and spending over time, and a few friends tested it for me.

The browser demo lets you record income and expenses, set a budget, and view an overview of your finances. Its data stays in the current browser. The repository also contains a separate Flask application with accounts and database-backed expense tracking.

**Technologies:** Python, Flask, SQLite, HTML, CSS, and JavaScript.
